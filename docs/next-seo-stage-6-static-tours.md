# Этап 6. Статические страницы экскурсий

## Что сделано

- Проверена страница `next/app/tours/[slug]/page.tsx`.
- Для страниц экскурсий используется `generateStaticParams()` на основе `next/src/data/tours.ts`.
- Для неизвестных slug-ов сохранен вызов `notFound()`.
- Добавлен `dynamicParams = false`, чтобы Next.js не пытался динамически генерировать страницы для slug-ов, которых нет в данных.
- Проверено, что H1, описание, программа, формат, продолжительность и цена берутся из данных тура и находятся в серверном HTML.

## Проверка

- `npm run build` в папке `next` проходит успешно.
- Next.js помечает `/tours/[slug]` как SSG.
- Сборка сгенерировала отдельные HTML-файлы для страниц экскурсий, например:
  - `.next/server/app/tours/obzornaya.html`
  - `.next/server/app/tours/detali.html`
  - `.next/server/app/tours/kreml.html`
- В `.next/server/app/tours/detali.html` найден видимый текст экскурсии: H1, описание, блок "О программе", "Что увидим", цена, формат и продолжительность.

## Результат

Этап 6 выполнен: каждая экскурсия из `tours.ts` получает статически сгенерированный HTML, пригодный для индексации без выполнения JavaScript.
